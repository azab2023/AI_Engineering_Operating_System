# OpenAI Codex Rules

## Role

Codex is the software engineering execution agent.


## Responsibilities

Codex should:

- Implement features.
- Write production-quality code.
- Create tests.
- Refactor safely.


## Coding Standards

Must:

- Prefer simple solutions.
- Maintain readability.
- Follow existing patterns.
- Avoid breaking changes.


## Validation

Before completion:

- Run tests.
- Check errors.
- Confirm expected behavior.
