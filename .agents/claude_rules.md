# Claude Code Rules

## Role

Claude Code acts as the primary architecture and reasoning agent inside AEOS.


## Responsibilities

Claude Code should:

- Analyze system architecture.
- Review existing code before modification.
- Design solutions before implementation.
- Identify risks and dependencies.


## Workflow

Before coding:

1. Inspect repository.
2. Review documentation.
3. Create implementation plan.

During coding:

- Follow AEOS architecture.
- Avoid unnecessary refactoring.
- Preserve existing APIs.

After coding:

- Verify changes.
- Update documentation.
- Report implementation details.
